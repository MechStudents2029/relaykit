# RelayKit

Production-style **TypeScript job relay** and resilience toolkit — built as a resume-grade systems project you can push on every weekday.

## What it demonstrates

- Redis Streams consumer groups
- Idempotent job processing
- Retry with exponential backoff + jitter
- Dead-letter queue (DLQ)
- Circuit breaker + bulkhead patterns
- OpenAPI-documented HTTP API
- Prometheus-style metrics endpoint
- Load-test harness + integration tests
- Docker Compose for local Redis
